PRIVATE AI SHORTS MAKER — STARTER WEBSITE

Deploy on Netlify:
1. Extract this ZIP on your Android phone.
2. Open https://app.netlify.com/drop in Chrome.
3. Sign in/create a free Netlify account.
4. Upload the extracted project folder (or ZIP if accepted).
5. Open the generated site URL.
6. Chrome menu ⋮ > Add to Home screen / Install app.

Included: mobile-first UI, YouTube embed preview (not downloader), manual transcript input, simple local hook-line suggestions (not AI), local browser save, JSON export, PWA manifest and service worker.

Not included yet: secure account authentication, AI API integration, authorized video-file processing, timestamps, subtitle generation, MP4 export.

Privacy: Local browser storage is not secure login and does not sync between devices. Do not put API keys in frontend code. Add backend authentication before treating a public deployment as private.
